## 1. 资产管理

### 1.1 资产层级建模 ✅

| 需求 | 说明 | 状态 |
|------|------|------|
| 空间层级 | 建筑物→楼层→房间等空间层级结构，支持无限嵌套 | ✅ |
| 设备管理 | 设备挂载在空间下，记录供应商、采购日期、保修日期 | ✅ |
| 服务抽象 | 设备通过服务（Service）连接协议驱动，管理连接池 | ✅ |
| 监测点（Probe） | 只读数据采集点，支持主动轮询和被动接收 | ✅ |
| 控制点（Control） | 可执行命令的执行器，下发控制指令 | ✅ |
| 资产树遍历 | Visitor 模式遍历资产树，支持类型安全的节点访问 | ✅ |
| 资产状态传播 | 子节点状态变化自动向上传播到父节点 | ✅ |
| 资产路径 | 计算并缓存资产在树中的完整路径 | ✅ |
| 资产类型体系 | AssetType/ProbeType/ControlType 等元数据定义 | ✅ |

| 资产列表查询 | 按类型过滤的扁平列表查询 | ✅ |
| 单资产详情 | 按 ID 查询单个资产详情 | ✅ |
