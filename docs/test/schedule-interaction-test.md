## 2. 任务列表

### TC-SCHED-03 任务数据展示

**前置条件**：存在定时任务数据

**预期结果**：
- [ ] 表格正确显示所有任务行
- [ ] 每行包含：ID、名称、目标（"名称 #ID" 或 "#ID"）、command、cronExpression
- [ ] 状态列显示 el-switch 组件，反映 enabled 状态
- [ ] 下次执行列显示时间或 "-"（disabled 任务）

### TC-SCHED-04 关键字搜索

**步骤**：
1. 在搜索输入框输入关键字（如 `每日`）
2. 点击搜索按钮
3. 点击清除按钮

**预期结果**：
- [ ] 点击搜索后 API 请求包含 `keyword=每日` 参数
- [ ] 表格仅显示名称匹配的任务
- [ ] 清除后恢复显示全部任务

### TC-SCHED-05 下次执行时间格式

**预期结果**：
- [ ] enabled 任务的 nextFireTime 显示为可读日期时间
- [ ] disabled 任务的 nextFireTime 显示为 "-"

## 3. 新增任务

### TC-SCHED-06 打开新增弹窗

**步骤**：
1. 点击"新增任务"按钮

**预期结果**：
- [ ] 弹窗标题为"新增任务"
- [ ] 表单字段：任务名称（必填）、目标监控器（必填，数字输入框 min=1 + 名称显示 + "点击左侧资产树可自动填充"提示）、命令（必填）、调度规则（CronWizard 向导/专家双模式）、描述（文本域）
- [ ] 所有字段初始为空（Cron 向导默认每天 08:00）

### TC-SCHED-07 提交新增

**步骤**：
1. 填写任务名称："每日开灯"
2. 目标监控器 ID 输入 `10`（或通过点击资产树节点自动填充）
3. 命令输入 "ON"
4. 调度规则保持向导模式默认每天 08:00（`0 0 8 * * ?`）
5. 点击"确定"

**预期结果**：
- [ ] 弹窗关闭
- [ ] 显示"创建成功"提示
- [ ] 列表刷新，新任务出现在表格中
- [ ] 新任务默认 enabled=true

### TC-SCHED-08 必填校验

**步骤**：
1. 打开新增弹窗
2. 不填写任何字段，直接点击"确定"

**预期结果**：
- [ ] 显示"请填写必填字段"警告
- [ ] 弹窗不关闭

### TC-SCHED-09 Cron 预览

**步骤**：
1. 填写有效的 Cron 表达式（如通过向导设置每天 08:00 → `0 0 8 * * ?`）
2. 观察预览

**预期结果**：
- [ ] 下次执行时间预览显示（如 "2026-05-29 08:00:00"）
- [ ] 无效 cron 表达式时不显示预览

## 9. CronWizard 向导组件

### TC-SCHED-23 向导模式 — 每天频率

**步骤**：
1. 打开新增弹窗，默认显示向导标签
2. 频率默认为"每天"，时间默认 08:00

**预期结果**：
- [ ] 向导标签页选中，频率为"每天"，时间为 08:00
- [ ] 表达式行显示 `0 0 8 * * ?`

### TC-SCHED-24 向导模式 — 每周频率

**步骤**：
1. 点击"每周"
2. 勾选星期一、三、五
3. 清空勾选

**预期结果**：
- [ ] 显示星期复选框
- [ ] 勾选 1,3,5 后表达式显示 `0 0 8 * * 1,3,5`
- [ ] 清空勾选时显示"请至少选择一个星期"警告

### TC-SCHED-25 向导模式 — 每月频率

**步骤**：
1. 点击"每月"
2. 日期下拉选择 1
3. 日期下拉选择"最后一天"

**预期结果**：
- [ ] 显示日期下拉（1-31 + 最后一天）
- [ ] 选择 1 时表达式显示 `0 0 8 1 * ?`
- [ ] 选择"最后一天"时表达式显示 `0 0 8 L * ?`

### TC-SCHED-26 向导↔专家标签切换 — 可解析表达式

**步骤**：
1. 在向导中设置每月/最后一天（表达式 `0 0 8 L * ?`）
2. 切换到专家标签
3. 切回向导标签

**预期结果**：
- [ ] 专家标签输入框显示 `0 0 8 L * ?`
- [ ] 切回向导后正确还原为"每月/08:00/最后一天"

### TC-SCHED-27 向导↔专家标签切换 — 不可解析表达式

**步骤**：
1. 切到专家标签
2. 输入 `0 */5 * * * ?`
3. 点击向导标签

**预期结果**：
- [ ] 切换被阻止，停留在专家标签
- [ ] 显示警告提示"当前表达式无法用向导表示，请继续在专家模式编辑"
