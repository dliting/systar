## 1. 页面导航与布局

### TC-OPS-01 页面加载

**步骤**：
1. 登录后导航到 `/operations`（或首页重定向）

**预期结果**：
- [ ] URL 为 `/operations`
- [ ] 左侧显示"资产树"面板，包含搜索框、展开/收起按钮、刷新按钮
- [ ] 右侧初始显示 `el-empty "请在左侧选择资产节点"`
- [ ] 页面无 JS 错误

### TC-OPS-02 URL 参数恢复节点选择

**步骤**：
1. 选择某节点后观察 URL
2. 复制 URL 到新标签页打开

**预期结果**：
- [ ] 选择节点后 URL 变为 `/operations?node=<id>`
- [ ] 新标签页打开后自动定位到对应节点并加载数据

## 2. 资产树交互

### TC-OPS-03 树节点展开/收起

**步骤**：
1. 点击根节点的展开箭头
2. 再次点击收起

**预期结果**：
- [ ] 子节点正确展开显示

- [ ] 每个节点显示对应图标（空间=FolderOpened, 设备=Monitor, Probe=Odometer, Control=Setting, Service=Service）

## 5. 资产 CRUD

### TC-OPS-17 新增子节点（空间）

**步骤**：
1. 选择一个 SPACE 节点
2. 点击"新增子节点"
3. 选择类型 "空间 (Space)"
4. 填写名称、标题
5. 可选填写面积、排序号、客户端可见开关
6. 点击"新增"

**预期结果**：
- [ ] 弹窗标题为"新增资产"
- [ ] 类型下拉包含：空间、设备、服务、监测器、控制器
- [ ] 必填校验：类型、名称、标题
- [ ] 提交后弹窗关闭，树刷新，新节点出现

### TC-OPS-18 新增子节点（Probe）

**步骤**：
1. 选择一个 DEVICE 节点
2. 点击"新增子节点"
3. 选择类型 "监测器 (Probe)"
4. 选择类型名
5. 观察表单变化

**预期结果**：
- [ ] 选择类型名后，扩展属性区域自动加载
- [ ] 表单字段根据类型动态显示：单位、采集间隔、存储间隔、告警条件、最小值、最大值
- [ ] 类型属性中 ViewType 特殊控件正确渲染（YESNO→开关, SLIDER/PERCENT→滑块, LIST→下拉, TEXTAREA→多行文本, PASSWORD→密码框, INT/FLOAT→数字输入）
- [ ] 默认值自动填充

### TC-OPS-19 编辑节点

**步骤**：
1. 选择任意节点
2. 点击"编辑"
3. 修改名称或标题
4. 点击"保存"

**预期结果**：
- [ ] 弹窗标题为"编辑资产 — <标题>"
- [ ] 表单预填当前值
- [ ] 类型字段不可修改（编辑模式无类型选择器）
- [ ] 保存后树刷新

### TC-OPS-20 删除节点

**步骤**：
1. 选择一个可删除的节点
2. 点击"删除"
3. 在确认对话框点击"删除"

**预期结果**：
- [ ] 弹出确认对话框 "确认删除「X」吗？删除后无法恢复。"
- [ ] 确认后调用 deleteAsset API
- [ ] 成功后树刷新，右侧恢复空状态
- [ ] 取消则无操作
