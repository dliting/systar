Systar Monitoring API

IoT 智能监控运维系统 REST API，提供资产树查询、实时/历史数据读取、控制命令执行、告警与联动规则管理等功能。

Interface Overview
方法路径说明
GET/api/monitor/tree获取资产树（递归树形结构）
GET/api/monitor/assets获取资产列表，支持 kind 过滤
GET/api/monitor/assets/{id}获取单个资产详情
GET/api/monitor/probe-values批量获取实时监测值
GET/api/monitor/probe-history分页获取历史数据
POST/api/monitor/control/{id}/execute执行控制命令
GET/api/monitor/alarm-rules获取告警规则列表
GET/api/monitor/alarm-messages分页获取告警消息
GET/api/monitor/linkage-rules获取联动规则（causes + effects）
WS/ws/monitor实时监测数据 WebSocket 推送
Base URL：默认为 http://127.0.0.1:8081，可通过 server.port 配置修改。WebSocket 地址为 ws://127.0.0.1:8081/ws/monitor。

1. 资产树查询

GET /api/monitor/tree

返回完整的资产树形结构，从根空间节点递归展开所有子节点。树节点按 SPACE → DEVICE → SERVICE / PROBE / CONTROL 的层级组织。

Request Parameters

无参数。

Response — AssetNodeVO
字段类型说明
idint资产 ID
namestring资产名称
captionstring显示标题
kindstring资产类型枚举：SPACE | DEVICE | SERVICE | PROBE | CONTROL
statestring状态枚举：NORMAL | WARNING | ERROR | OFFLINE
childrenlist[AssetNodeVO] | null子节点列表，叶节点为 null
curl Examples 
curl {BASE}/api/monitor/tree
curl {BASE}/api/monitor/tree
Invoke-RestMethod -Uri "{BASE}/api/monitor/tree"

Response:

{
  "code": 0,
  "message": "success",
  "data": {
    "id": -1,
    "name": "root",
    "caption": "root",
    "kind": "SPACE",
    "state": "NORMAL",
    "children": [
      {
        "id": 1,
        "name": "floor1",
        "caption": "1号厂房",
        "kind": "SPACE",
        "state": "NORMAL",
        "children": [
          {
            "id": 10,
            "name": "temp_sensor",
            "caption": "温度传感器",
            "kind": "PROBE",
            "state": "NORMAL",
            "children": null
          }
        ]
      }
    ]
  }
}

2. 资产列表查询

GET /api/monitor/assets

返回扁平化的资产列表，支持按 kind 过滤。不传参数时返回全部资产。

Query Parameters
字段类型必填缺省说明
kindstring否无资产类型过滤：SPACE | DEVICE | SERVICE | PROBE | CONTROL
Response — AssetVO
字段类型说明
idint资产 ID
namestring资产名称
captionstring显示标题
kindstring资产类型枚举
statestring状态枚举
parentIdint父节点 ID
enabledbool是否启用
pathstring完整路径，如 "root->floor1->deviceA"
valueobject | null当前值（仅 PROBE / CONTROL 类型有值）
lastDetectTimelong | null最近检测时间戳（毫秒），仅 Monitor 类型
curl Examples 
# 获取所有资产
curl {BASE}/api/monitor/assets

# 仅获取探头
curl "{BASE}/api/monitor/assets?kind=PROBE"
:: 获取所有资产
curl {BASE}/api/monitor/assets

:: 仅获取探头
curl "{BASE}/api/monitor/assets?kind=PROBE"
# 获取所有资产
Invoke-RestMethod -Uri "{BASE}/api/monitor/assets"

# 仅获取探头
Invoke-RestMethod -Uri "{BASE}/api/monitor/assets?kind=PROBE"

Response:

{

Query Parameters
字段类型必填缺省说明
monitorIdint是—监测点 ID
startTimedatetime否无限制起始时间（ISO 8601 格式，如 2025-01-01T00:00:00）
endTimedatetime否无限制结束时间（ISO 8601 格式）
pageint否1页码
sizeint否50每页记录数
Response — 分页结构
字段类型说明
totallong总记录数
pagelong当前页码
sizelong每页记录数
recordslist[SampleFloatEntity]采样记录数组
SampleFloatEntity
字段类型说明
idlong记录 ID
monitorIdint监测点 ID
valuefloat采样值
sampleTimedatetime采样时间
curl Examples

curl "{BASE}/api/monitor/probe-history?monitorId=10"

curl "{BASE}/api/monitor/probe-history?monitorId=10&startTime=2025-01-01T00:00:00&endTime=2025-01-02T00:00:00&page=1&size=20"

6. WebSocket 实时推送

WS /ws/monitor WebSocket

通过 WebSocket 实时推送监测数据变更。连接后默认接收所有监测点的数据推送；可通过 subscribe 消息订阅指定监测点，仅接收订阅范围内的数据。

连接地址：ws://127.0.0.1:8081/ws/monitor。允许的来源：http://localhost:*。
Client → Server 消息
action说明请求体
subscribe订阅指定监测点{"action":"subscribe","monitorIds":[1,2,3]}
unsubscribe取消订阅，恢复接收全部{"action":"unsubscribe"}
Server → Client 推送格式
字段类型说明
monitorIdint监测点 ID
valueobject当前值
statusstring状态：NORMAL | WARNING | ERROR | OFFLINE
sampleTimelong采样时间戳（毫秒）
JavaScript Example 
// 建立连接
const ws = new WebSocket('ws://127.0.0.1:8081/ws/monitor');

ws.onopen = () => {
  console.log('Connected');

  // 订阅监测点 10 和 11
  ws.send(JSON.stringify({
    action: 'subscribe',
    monitorIds: [10, 11]
  }));
};

ws.onmessage = (event) => {
  const data = JSON.parse(event.data);
  console.log(`Monitor ${data.monitorId}: ${data.value} (${data.status})`);
};

ws.onerror = (err) => console.error('WebSocket error', err);
ws.onclose = () => console.log('Disconnected');

7. 控制命令执行

POST /api/monitor/control/{id}/execute application/json

向指定控制资产发送执行命令。目标资产必须是 CONTROL 类型，否则返回错误。

Path Parameters
参数类型说明
idint控制资产 ID
Request Body
字段类型必填说明
commandstring是控制命令值
curl Examples 
curl -X POST {BASE}/api/monitor/control/20/execute \
  -H "Content-Type: application/json" \
  -d '{"command": "1"}'
curl -X POST {BASE}/api/monitor/control/20/execute ^
  -H "Content-Type: application/json" ^
  -d "{\"command\": \"1\"}"
$body = @{command = "1"} | ConvertTo-Json
Invoke-RestMethod -Uri "{BASE}/api/monitor/control/20/execute" -Method POST -ContentType "application/json" -Body $body

Response (成功):

{
  "code": 0,
  "message": "success",
  "data": "success"
}

Response (资产未找到):

{
  "code": 1,
  "message": "Asset 999 not found.",
  "data": null
}

Response (非控制类型):

{
  "code": 1,
  "message": "Asset 10 is not a control.",
  "data": null
}

字段类型说明

附录 A. 统一响应格式

所有 REST API 均使用统一的 Result<T> 包装响应，JSON 结构如下：

Result<T> 结构
字段类型说明
codeint状态码：0 = 成功，1 = 一般错误
messagestring状态描述
dataT | null响应数据，失败时为 null
Success Example 
{
  "code": 0,
  "message": "success",
  "data": { ... }
}
Error Example 
{
  "code": 1,
  "message": "Asset not found: 999",
  "data": null
}

说明：通过服务地址访问时（如 http://127.0.0.1:8081/api_doc.html），curl 示例中的 {BASE} 替换为 http://127.0.0.1:8081。直接打开本 HTML 文件时需手动替换。Windows CMD 中 JSON 内部双引号需用 \" 转义。
