Systar Monitoring API

IoT 智能监控运维系统 REST API，提供资产树查询、实时/历史数据读取、控制命令执行、告警与联动规则管理等功能。

Interface Overview
方法路径说明
GET/api/monitor/asset-tree获取资产森林（按类型虚拟树或自定义分组树）
GET/api/monitor/group-trees获取分组树列表
POST/api/monitor/group-trees新增分组树
PUT/api/monitor/group-trees/{id}更新分组树
DELETE/api/monitor/group-trees/{id}删除分组树（须先删空全部分组）
GET/api/monitor/groups获取树内分组列表（含成员资产 id）
POST/api/monitor/groups新增分组
PUT/api/monitor/groups/{id}更新分组（改名 / 移动）
DELETE/api/monitor/groups/{id}删除分组（须无子分组、无成员）
PUT/api/monitor/groups/{id}/assets整体替换分组成员（仅 DEVICE/SERVICE）
GET/api/monitor/assets获取资产列表，支持 kind 过滤
GET/api/monitor/assets/{id}获取单个资产详情
GET/api/monitor/probe-values批量获取实时监测值
GET/api/monitor/probe-history分页获取历史数据
POST/api/monitor/control/{id}/execute执行控制命令

Base URL：默认为 http://127.0.0.1:8081，可通过 server.port 配置修改。WebSocket 地址为 ws://127.0.0.1:8081/ws/monitor。

1. 资产森林查询

GET /api/monitor/asset-tree

返回资产森林（顶层节点列表）。tree=kind（缺省）为虚拟"按类型"树：服务 / 设备两个合成根，监测器与控制器挂在所属设备下；tree=<分组树id> 返回对应的自定义分组树，未挂分组的设备 / 服务进入"未分组"节点。成员写入（拖拽挂载 / 卸载、PUT /groups/{id}/assets）一律使用 t_asset 行 id 空间（即 assetRowId）；POST /assets 创建资产的响应 data 亦为该行 id（分组成员 id），而非运行时 id。

Query Parameters
字段类型必填缺省说明
treestring否kind树选择器：kind（按类型）或分组树 id
Response — TreeNodeVO
字段类型说明
keystring复合节点键：GROUP:<id> | ASSET:<id> | KIND:<KIND> | UNGROUPED（分组 id 与资产 id 相互独立，UI 的 node-key 必须用该键）
nodeKindstringASSET（资产节点）| GROUP（分组 / 合成根节点）
assetKindstring | null资产类型：DEVICE | SERVICE | PROBE | CONTROL；分组节点为 null
idlong | null资产运行时 id（/assets CRUD API 的寻址 id）或分组 id；合成节点（类型根、未分组）为 null。两个 id 空间相互独立
assetRowIdlong | null资产在 t_asset 统一视图的行 id（分组成员 id，挂载 / 卸载写入必须用它）；分组与合成节点为 null，资产无视图行时也为 null
namestring名称（分组为英文标识）
captionstring显示标题
statestring | null状态枚举（仅资产节点）：NORMAL | WARNING | ERROR | OFFLINE
enabledbool | null是否启用（仅资产节点）
childrenlist[TreeNodeVO]子节点列表；叶节点为空列表
curl Examples 
curl "{BASE}/api/monitor/asset-tree?tree=kind"
curl "{BASE}/api/monitor/asset-tree?tree=kind"

分组树与分组管理

用户自管理分组树及树内分组的 CRUD；"按类型"树为虚拟计算不占行。分组仅是组织视角的附加层（monitor-core 不感知），成员资产仅限 DEVICE / SERVICE。权限复用 iot:asset:list / add / edit / delete，校验失败统一返回 400 与原因。

Endpoints
方法路径权限说明
GET/api/monitor/group-treesiot:asset:list分组树列表（按 sequence 排序）
POST/api/monitor/group-treesiot:asset:add新增分组树（name 全局唯一）
PUT/api/monitor/group-trees/{id}iot:asset:edit更新分组树（name/caption/sequence）
DELETE/api/monitor/group-trees/{id}iot:asset:delete删除分组树（须先删空全部分组）
GET/api/monitor/groups?treeId={treeId}iot:asset:list树内分组列表（含成员资产行 id）
POST/api/monitor/groupsiot:asset:add新增分组（parent 缺省 0 = 顶层，level 自动维护）
PUT/api/monitor/groups/{id}iot:asset:edit更新分组：改名（name）和/或移动（parent + treeId）
DELETE/api/monitor/groups/{id}iot:asset:delete删除分组（须无子分组、无成员资产）
PUT/api/monitor/groups/{id}/assetsiot:asset:edit整体替换分组成员
GroupTreeVO（GET /group-trees 响应项）
字段类型说明
idlong分组树 id（用作 /asset-tree?tree= 选择器）
namestring树标识（英文，全局唯一）
captionstring显示名
sequenceint排序号
GroupVO（GET /groups 响应项）
字段类型说明
idlong分组 id
treeIdlong所属分组树 id
namestring分组标识（树内唯一）
captionstring显示名
parentlong父分组 id；0 = 顶层
levelint层级（顶层 = 1，移动时自动重算子树）
sequenceint排序号
assetIdslist[long]直接成员资产的 t_asset 行 id
请求体
端点字段必填说明
POST /group-trees
PUT /group-trees/{id}		name是树标识，去空白后全局唯一
caption否显示名；缺省取 name
sequence否排序号；POST 缺省 0，PUT（更新）缺省 = 保留现值
POST /groupstreeId是目标分组树 id（缺失按 0 处理，报"树不存在"）
name是分组标识，树内唯一
caption否显示名；缺省取 name
parent否父分组 id，缺省 0 = 顶层；须属同一棵树
sequence否排序号，缺省 0
PUT /groups/{id}parent移动时新父分组 id（0 = 移到顶层）；与 treeId 成对出现；不可移入自身子树
treeId移动时分组所在树 id（移动模式校验用）
name改名时新分组标识，树内唯一
caption否新显示名；缺省取 name
sequence否排序号，缺省 = 保留现值；name 与 parent+treeId 均未提供时报"Nothing to update"
PUT /groups/{id}/assetsassetIds否成员资产 t_asset 行 id 全量列表（统一视图行 id，非运行时资产 id）；null/缺省 = 清空成员。id 重复、不存在或为 PROBE/CONTROL 种类时整批拒绝（400）
curl Examples 
curl "{BASE}/api/monitor/group-trees"
curl -X POST "{BASE}/api/monitor/group-trees" -H "Content-Type: application/json" \
     -d '{"name": "floor", "caption": "楼层", "sequence": 1}'
curl "{BASE}/api/monitor/groups?treeId=1"
curl "{BASE}/api/monitor/group-trees"
curl -X POST "{BASE}/api/monitor/group-trees" -H "Content-Type: application/json" -d "{\"name\": \"floor\", \"caption\": \"楼层\", \"sequence\": 1}"
curl "{BASE}/api/monitor/groups?treeId=1"
Invoke-RestMethod -Uri "{BASE}/api/monitor/group-trees"
Invoke-RestMethod -Uri "{BASE}/api/monitor/group-trees" -Method Post -ContentType "application/json" -Body '{"name": "floor", "caption": "楼层", "sequence": 1}'
Invoke-RestMethod -Uri "{BASE}/api/monitor/groups?treeId=1"

6. WebSocket 实时推送

WS /ws/monitor WebSocket

通过 WebSocket 实时推送监测数据变更。连接后默认接收所有监测点的数据推送；可通过 subscribe 消息订阅指定监测点，仅接收订阅范围内的数据。

连接地址：ws://127.0.0.1:8081/ws/monitor。允许的来源：http://localhost:*。
Client → Server 消息
action说明请求体
subscribe订阅指定监测点{"action":"subscribe","monitorIds":[1,2,3]}
unsubscribe取消订阅，恢复接收全部{"action":"unsubscribe"}
Server → Client 推送格式
字段类型说明
monitorIdint监测点 ID
valueobject当前值
statusstring状态：NORMAL | WARNING | ERROR | OFFLINE
sampleTimelong采样时间戳（毫秒）
JavaScript Example 
// 建立连接
const ws = new WebSocket('ws://127.0.0.1:8081/ws/monitor');

ws.onopen = () => {
  console.log('Connected');

  // 订阅监测点 10 和 11
  ws.send(JSON.stringify({
    action: 'subscribe',
    monitorIds: [10, 11]
  }));
};

ws.onmessage = (event) => {
  const data = JSON.parse(event.data);
  console.log(`Monitor ${data.monitorId}: ${data.value} (${data.status})`);
};

ws.onerror = (err) => console.error('WebSocket error', err);
ws.onclose = () => console.log('Disconnected');

7. 控制命令执行

POST /api/monitor/control/{id}/execute application/json

向指定控制资产发送执行命令。目标资产必须是 CONTROL 类型，否则返回错误。

Path Parameters
参数类型说明
idint控制资产 ID
Request Body
字段类型必填说明
commandstring是控制命令值
curl Examples 
curl -X POST {BASE}/api/monitor/control/20/execute \
  -H "Content-Type: application/json" \
  -d '{"command": "1"}'
curl -X POST {BASE}/api/monitor/control/20/execute ^
  -H "Content-Type: application/json" ^
  -d "{\"command\": \"1\"}"
$body = @{command = "1"} | ConvertTo-Json
Invoke-RestMethod -Uri "{BASE}/api/monitor/control/20/execute" -Method POST -ContentType "application/json" -Body $body

Response (成功):

{
  "code": 0,
  "message": "success",
  "data": "success"
}

Response (资产未找到):

{
  "code": 1,
  "message": "Asset 999 not found.",
  "data": null
}

Response (非控制类型):

{
  "code": 1,
  "message": "Asset 10 is not a control.",
  "data": null
}
